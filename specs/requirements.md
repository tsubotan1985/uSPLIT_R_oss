# microSPLIT-R - Requirements Document

Windowsで動作する Python-GUI アプリ。MiniPIX TPX (Standard) 3台を同時接続し、連続データ取得と準リアルタイム分析を実施。測定データの保存、α/β/γ線分類、エネルギースペクトル生成、LGBM機械学習モデルの学習・評価・可視化を行う。

## Core Features

### 1. マルチデバイス制御
- MiniPIX TPX (Standard) 3台の同時接続・制御
- Pixet SDK (`pypixet.pyd`) によるハードウェアアクセス
- デバイスID (`E02`, `I03`, `J03`) に基づくキャリブレーションXMLの自動マッチング
- スレッドセーフなデバイス制御 (`threading.Lock` 必須)

### 2. 連続データ取得
- 設定可能な測定インターバル (0.1秒 / 1秒 / 10秒) で3台同時フレーム取得
- `.out` 形式でのファイル保存
- タイムスタンプ付き測定フォルダ自動作成
- センサー別サブフォルダ (`Sensor01/`, `Sensor02/`, `Sensor03/`) へのファイル振り分け

### 3. 準リアルタイム分析
- `.out` ファイルからの強度データ読み込みと前処理（デッドピクセル/エッジクリッピング）
- `skimage.measure.regionprops` を用いた14特徴量抽出
- LightGBM モデルによる α/β/γ 線分類
- エネルギースペクトルヒストグラム生成
- 時系列データ（フレーム別クラスターカウント）集計

### 4. GUI 可視化 (PySide6)
- **測定タブ**: 測定制御（Start/Stop、インターバル選択、保存先設定）、3センサー別リアルタイムカウント/温度/接続状態表示、時系列プロット、エネルギースペクトル表示
- **学習タブ**: α/β/γ 線源フォルダ選択、LGBM学習パイプライン実行、進捗表示、混同行列・特徴量重要度の可視化
- 共通ログパネルによる測定・分析イベントのリアルタイム表示

### 5. 機械学習パイプライン
- α/β/γ 標準線源データからの教師あり学習
- 14特徴量の並列抽出とラベル付与
- LightGBM 分類器の学習 + Optuna ハイパーパラメータ最適化
- 学習済みモデルの `.joblib` + メタデータJSON 保存
- 測定タブでの学習済みモデル自動読み込みと推論適用

## User Stories

- 研究者として、MiniPIX 3台を同時に操作し、放射線データを途切れなく収集したい
- 分析者として、収集したデータから α/β/γ 線を自動分類し、エネルギースペクトルを可視化したい
- モデル開発者として、標準線源データを使って LGBM 分類モデルを GUI 上で学習・評価したい
- オペレーターとして、センサーごとのリアルタイムカウントと温度を一目で監視したい

## Acceptance Criteria

- [ ] 3台の MiniPIX が同時に認識され、同一インターバルでデータ取得できること
- [ ] デバイスIDに応じた適切なキャリブレーションXMLが自動選択されること
- [ ] `.out` ファイルが `{測定ルート}/SensorXX/frame_NNNNNN.out` の命名規則で保存されること
- [ ] 測定フレーム取得を優先し、分析処理は測定の隙間時間で実行されること（測定割り込み機構）
- [ ] α/β/γ 分類結果が GUI 上でリアルタイム更新されること
- [ ] 学習パイプライン完了後、混同行列と分類レポートが正しく表示されること
- [ ] デバイス未接続時・切断時に適切なエラーハンドリングが行われ、GUIがクラッシュしないこと
- [ ] テストカバレッジが主要モジュールで担保されていること（TDD: Red-Green-Refactor）

## Non-functional Requirements

- **パフォーマンス**: 測定インターバルは 0.1秒/1秒/10秒 の3段階。センサーの信号伝達ラグがあるため、0.1秒設定時は「1秒周期のうち0.1秒間測定・残りは待機」のデューティサイクル動作となる。GUI更新が測定スレッドをブロックしないこと
- **スレッド安全性**: `pypixet` は非スレッドセーフのため、すべてのハードウェアアクセスを `threading.Lock` で保護すること
- **互換性**: Python 3.12 固定（Pixet SDK `.pyd` 互換性）。Windows のみ
- **耐障害性**: シングルデバイス切断時も他デバイスの測定を継続できること
- **ファイルI/O**: 測定スレッドと分析スレッド間のファイル読み書き競合を防止する atomic 操作の実装
